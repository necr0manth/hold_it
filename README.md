# Mana and Artifice addon "Hold it!"
![Icon](https://github.com/Tamerik0/hold_it/blob/main/logo.png?raw=true)
## About "Hold it"
Hold It adds five powerful concentration-based spells to Mana and Artifice that require charging to achieve maximum effectiveness. Instead of instant casting, these spells use a hold-to-charge mechanic where longer preparation creates exponentially more powerful effects.

## Spells

- **Swordstorm** opens dimensional rifts that launch spectral blades at nearby enemies.
- **Aura** creates a charged spherical field for large-scale area effects.
- **Coalescence** summons multiple magical orbs with optional homing and synchronized attacks.
- **Vortex** forms a delayed, targeted explosion that can affect blocks, entities, or both.
- **Greater Projectile** creates a slow, high-density projectile with a powerful area impact.
