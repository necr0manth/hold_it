# Mana and Artifice addon "Hold it!"
![Icon](https://github.com/Tamerik0/hold_it/blob/main/logo.png?raw=true)
## About "Hold it"
Hold It adds five powerful concentration-based spells to Mana and Artifice that require charging to achieve maximum effectiveness. Instead of instant casting, these spells use a hold-to-charge mechanic where longer preparation creates exponentially more powerful effects.
